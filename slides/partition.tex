\section{Retention Strategy}
\begin{frame}
\frametitle{Retention Strategy}
\framesubtitle{Partitioning in disguise}

\begin{itemize}
  \item Retained tensor's producer and consumer should be in separate subgraphs
  \item In other words, selecting retained tensors means partitioning a subgraph
  \item How to partition efficiently?
  \pause
  \item Shi et. al., Welder: Scheduling Deep Learning Memory Access via Tile-graph. (OSDI '23)
  \begin{itemize}
    \item Introduces \texttt{GraphConnecting} algorithm for assigning memory tiers for tensors
  \end{itemize}
  \pause
  \item Our partitioner selects ephemeral or fast memory for tensors
  \begin{itemize}
    \item Iterate over each internal tensor and determine whether the tensor should be retained
    \item Based on \texttt{GraphConnecting}, exteded it to use beam search for better result
  \end{itemize}
\end{itemize}
\end{frame}
